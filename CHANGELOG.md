# Changelog

## 0.1.0a1 — prepared, unreleased

- Prepare an alpha package for reproducible point-in-time SEC fundamentals.
- Add authentic historical fiscal-calendar and revision/restatement audit ledgers,
  with conservative diagnostics and original narrative provenance.
- Add deterministic validation jobs, verified issuer checkpoints, resume equivalence,
  corruption rejection, writer locking, and batch failure records.
- Expand the purposive validation universe from 50 to 100 ordinary US-GAAP issuers.
- Include a small authentic offline panel example in installed artifacts.
- Document the public/experimental/private API boundary and supported Python 3.12.
- Add first-party tzdata fallback for systems without an IANA timezone database.
- Add cross-platform CI configuration and separate clean wheel/sdist install checks.
- Prepare researcher onboarding, source notices, validation evidence, and release checklist.

No new financial metric or unsupported sector ontology was added. Existing reported
metric defaults and accounting selection rules are unchanged. The package/software
identity changes intentionally; exact older receipts require matching older software.
Prior work packages remain the historical baseline, not separate published releases.
